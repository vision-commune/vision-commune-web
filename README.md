# Vision-Commune

Prototype du site Vision-Commune, agence Web & IA pour les collectivités locales.

## Site

Le site est une page HTML statique : `index.html` à la racine du dépôt. Aucun outil de compilation n'est nécessaire.

## Déploiement

La branche de production est `main`. Ce dépôt est relié au projet Vercel `vision-commune` pour déployer automatiquement les changements publiés sur cette branche.
